AI Spam Detector

A Machine Learning project built using Python to classify messages as spam or normal.

Features

- Detects spam messages
- Classifies normal messages
- Uses TF-IDF for text processing
- Uses Machine Learning for prediction

Technologies Used

- Python
- Pandas
- Scikit-learn

How to Run

1. Install Python.

2. Install the required libraries:
   
   "pip install pandas scikit-learn"

3. Run the program:
   
   "python train_model.py"

4. Enter a message and check the prediction.

Project Goal

To explore how Machine Learning can help identify spam messages automatically.
